تطبيق ذكي يقوم بجمع منشورات Reddit المميزة وتلخيصها بالذكاء الاصطناعي (Genkit + Gemini).

## 🚀 كيفية النشر والرفع على GitHub (الخطوات النهائية)

بما أنك قمت بتجهيز المشروع، إليك الأوامر التي يجب تنفيذها في الـ Terminal الخاص بك لرفع الكود إلى GitHub:

### 1. الرفع إلى GitHub لأول مرة
افتح Terminal داخل مجلد المشروع ونفذ الأوامر التالية بالترتيب:
```bash
# تهيئة المستودع
git init

# إضافة جميع الملفات
git add .

# تسجيل التغييرات (Commit)
git commit -m "النسخة النهائية: مشروع Side Hunt جاهز للنشر"

# تعيين الفرع الرئيسي
git branch -M main

# ربط المشروع بمستودعك على GitHub (استبدل الرابط برابط مستودعك الجديد)
# مثال: git remote add origin https://github.com/YOUR_USERNAME/side-hunt.git
git remote add origin [رابط_مستودعك_هنا]

# رفع الكود
git push -u origin main
```

### 2. التحديثات القادمة (Push to Main)
عند إجراء أي تعديل جديد، استخدم هذه الأوامر الثلاثة فقط:
```bash
git add .
git commit -m "وصف التعديل الجديد"
git push origin main
```

## ✨ المميزات الحالية في Side Hunt
- **نظام فلترة متقدم:** تبديل سلس بين مصادر (Side Hunts, Websites, AI & Code).
- **نظام المفضلة (Bookmarks):** حفظ المنشورات المهمة للرجوع إليها لاحقاً (مخزنة محلياً).
- **الوضع الليلي (Night Mode):** واجهة مريحة للعين بتصميم Grayscale عصري.
- **توب 15 اليومي:** نظام ذكي يعرض فقط منشورات "اليوم" لضمان الحداثة.
- **PWA جاهز:** يمكن تثبيته كتطبيق على الهاتف (APK-like experience).
- **حصة مجانية:** 15 طلباً يومياً مع إمكانية التصفير للاختبار.

## 🛠 المتطلبات التقنية للنشر (على Vercel)
عند النشر، تأكد من إضافة المتغير التالي في إعدادات البيئة (Environment Variables):
- `GOOGLE_GENAI_API_KEY`: مفتاح Gemini الخاص بك من Google AI Studio.
