# **App Name**: IdeaDigest

## Core Features:

- RSS Feed Fetching: Fetch and parse RSS feeds from Reddit using http and webfeed packages.
- AI-Powered Summarization: Use a generative AI tool to generate concise summaries of article content via a REST API.
- Card-Based Display: Display articles as cards with titles and AI-generated summaries.
- Copy Summary: Allow users to copy the AI-generated summary to their clipboard.
- Open in Browser: Provide a button to open the original article link in an external browser.
- RTL Support: Enable right-to-left (RTL) layout for Arabic language support.

## Style Guidelines:

- Primary color: Dark Blue (#1A237E) to create a sense of focused and calm browsing.
- Background color: Very dark blue (#0A0F35). 
- Accent color: Electric Purple (#BF5AF2) for interactive elements and highlights.
- Body font: 'Inter', a sans-serif font, for clear readability of summaries and descriptions.
- Headline font: 'Space Grotesk', a sans-serif font, for a techy modern look
- Use simple, clear icons for actions like copying and opening links.
- Cards should have a clean and well-organized layout with clear separation of title, summary, and action buttons.
